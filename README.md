# GolfCurse

A project that originally started out as just golf for Hackclub **Wrong**, this is now just a small little game/demo collection all made using **curses** the python wrapper for ncurse.  

# How to Play
## Golf
To play golf, use the arrow keys to adjust shot power, visible at the top, then hit enter to fire! Your goal is to get within 5 units of the flag. Note that there are different ground markings. = is flat ground, normal physics, H is the hole which has a flag above that gets removed when within 25m, S is sand that way cuts down your velocity, and is difficult to get out of, and W is water, which sends you back to the start.
## Snake
Literally just... Snake. We all know it, we all love it, just use the arrow keys.
## Sand
Not really a game just testing something cause I wanna make plinko. Hit enter to spawn sand.
